# Lucky Garg Portfolio

A modern, responsive personal portfolio website for Lucky Garg, built with HTML, CSS, and JavaScript.

## Live Sections
- Hero / Intro
- About
- Skills
- Projects
- Hackathons
- Achievements
- Contact

## Highlights
- Dark developer-style UI inspired by a modern portfolio design
- Dedicated hackathon showcase card for Guidewire DEVTrails 2026
- Achievement card focused on competitive programming progress
- Icon-based social contact links (Email, LinkedIn, GitHub)
- Smooth card hover interactions across key sections
- Mobile-friendly responsive layout

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Project Structure
- `index.html` - page structure and content
- `style.css` - styling, layout, and animations
- `script.js` - navigation menu toggle behavior

## Run Locally
1. Clone the repository.
2. Open `index.html` directly in your browser.
