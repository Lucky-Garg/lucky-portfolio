# Personal Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Clean UI with dark mode support
- Smooth scrolling and scroll animations
- Animated skill bars and project cards
- Responsive design for various devices
- Developer-style theme

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## How to View
Simply open the `index.html` file in your preferred web browser to view the portfolio.
